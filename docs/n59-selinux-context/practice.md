# Practice task: SELinux contexts

Work as `student`, in a virtual machine. No preparation is needed.

**Task.** Create the file `~/context.txt` with two lines:

1. line 1: the SELinux type of the file `/etc/shadow`
2. line 2: the SELinux type of the running sshd process

Only the type, the third field of the context. Then run the checker: `bash check.sh`.

The solution is in `solution.md`. Try first.
