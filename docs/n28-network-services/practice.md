# Practice task: bring a service back

Work as `student` (use `sudo` where needed).

1. Stop `chronyd` and disable it, so it neither runs now nor starts at boot.
2. Run the checker (`bash check.sh`) and read the two FAIL lines.
3. Enable `chronyd` and start it again, in one command.
4. Run the checker again.
5. Reboot, then run the checker once more.

The solution is in `solution.md`. Try first.
