# Practice task: restrict network access with firewalld

Work as `student`, in a virtual machine. Make sure firewalld is installed and running first.

**Task.**

1. Allow the service `https`.
2. Open port `5000/tcp`.
3. Remove the service `dhcpv6-client`.
4. Make all changes permanent and apply them.
5. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
