# Practice task: create, delete, and modify local user accounts

Work as `student`, in a virtual machine. First create a user to delete: `sudo useradd temp`.

**Task.**

1. Create the user `sam` with user ID `3001` and the comment `Sam Smith`.
2. Change the shell of `sam` to `/usr/sbin/nologin`.
3. Delete the user `temp`, including its home directory.
4. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
