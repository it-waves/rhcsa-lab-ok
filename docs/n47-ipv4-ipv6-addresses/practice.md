# Practice task: configure IPv4 and IPv6 addresses

Work as `student`. Use a virtual machine.

**Task.**

1. Create a connection called `exam0` on a dummy interface called `dummy1`.
2. Give it the static IPv4 address `10.20.30.40/24` and the static IPv6 address `fd00:20::40/64`.
3. Activate it.
4. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
