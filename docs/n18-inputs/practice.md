# Practice task: who lives where

Work in your home directory.

1. Create the folder `lab18`.
2. In it, create a script `who.sh` (use vim).
3. Given a name and a city as arguments, it prints `NAME lives in CITY`.
4. With fewer than 2 arguments it prints a line starting with `Usage` and exits with status 1.
5. Make the script executable.
6. Reboot, then run the checker (`bash check.sh`).

Example: `lab18/who.sh Zed Rome` prints `Zed lives in Rome`.

The solution is in `solution.md`. Try first.
