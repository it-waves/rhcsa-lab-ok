# Practice task: plan, reboot, record

Work as `student`, using `sudo` where needed.

1. Schedule a power off in 20 minutes (`shutdown`), then cancel it.
2. Reboot the machine normally.
3. After it is back, create the folder `lab20` in your home directory.
4. Save the output of `who -b` in the file `lab20/boot.txt`.
5. Run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
