# Practice task: grep

Create `server.log` first (see README). Then, on your own lab machine:

1. Create the directory `lab4` in your home directory.
2. Use `grep` with the option that ignores case to find the lines containing "error" in `server.log`.
3. Send those lines into `lab4/errors.txt`.
4. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
