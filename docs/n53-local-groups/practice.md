# Practice task: create, delete, and modify local groups and group memberships

Work as `student`, in a virtual machine. First prepare (one command per line):

```
sudo useradd erin
sudo useradd frank
sudo groupadd temp
```

**Task.**

1. Create the group `ops` with group ID `4000`.
2. Add `erin` and `frank` to `ops`.
3. Delete the group `temp`.
4. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
