# Practice task: a script that decides

Work in your home directory.

1. Create the folder `lab16`.
2. In it, create a script `exists.sh` (use vim).
3. The script prints `found` if `/etc/hosts` is a regular file, and `missing` if it is not.
4. Make the script executable.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
