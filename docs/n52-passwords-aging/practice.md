# Practice task: change passwords and adjust password aging

Work as `student`, in a virtual machine. First create a user: `sudo useradd dave`.

**Task.**

1. Set a password for `dave`.
2. Set the minimum days to 2, the maximum days to 60 and the warning days to 10.
3. Force `dave` to change the password at the next login.
4. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
