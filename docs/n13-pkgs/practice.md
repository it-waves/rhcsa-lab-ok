# Practice task: find, install, remove

Work in your home directory.

1. Create the folder `lab13`.
2. Use `dnf provides` to find the package that supplies the file `/usr/bin/telnet`. Write that package name on line 1 of `lab13/answer.txt`.
3. Install that package.
4. Install the package `tree`, then remove it again.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
