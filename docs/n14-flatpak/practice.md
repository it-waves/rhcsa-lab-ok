# Practice task: a Flatpak repository

1. Make sure Flatpak is installed.
2. Add the Flathub repository system-wide and name it `labhub`. Address: https://dl.flathub.org/repo/flathub.flatpakrepo
3. Disable `labhub`.
4. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
