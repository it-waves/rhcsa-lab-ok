# Command reference

| Command | What it does |
|---|---|
| `dnf repolist` | list enabled repositories |
| `sudo dnf install -y NAME` | install from a repository |
| `sudo dnf upgrade -y NAME` | update one package |
| `sudo dnf upgrade -y` | update every package |
| `sudo dnf remove -y NAME` | uninstall |
| `dnf download NAME` | save the rpm file in this folder |
| `sudo dnf install -y ./FILE.rpm` | install from a file on disk |
| `rpm -q NAME` | is it installed? which version? |
