# Practice task: install from a repository and from a file

Work as `student`, in your home directory.

**Setup (once).**

```
sudo dnf -y install dnf-plugins-core
sudo dnf -y remove tree lsof
```

**Task.**

1. Install `tree` from the repository.
2. Download the `lsof` RPM file into your home directory.
3. Install `lsof` from that file.
4. Run the checker (`bash check.sh`), reboot, and run it again.

The solution is in `solution.md`. Try first.
