# Command reference

| Command | What it does |
|---|---|
| `id` | who am I: user, group and group list |
| `ls -l FILE` | owner, group and permissions of a file |
| `namei -l PATH` | permissions of every folder on the way to the file |
| `chmod u+x FILE` | give the owner the execute bit |
| `chmod 755 FOLDER` | owner rwx, group and others r-x |
| `chown USER FILE` | change the owner of a file |
| Folder bits | `r` list, `w` add or remove files, `x` enter |
