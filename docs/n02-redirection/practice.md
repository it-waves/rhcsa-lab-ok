# Practice task: redirection

Do this on your own lab machine, then reboot and run the checker (`bash check.sh`).

1. Create the directory `lab3` in your home directory.
2. Run `ls` on the two paths `/etc/hostname` and `/nonexistent` in one command.
3. The normal output must go to `~/lab3/ok.txt`.
4. The error message must go to `~/lab3/err.txt`.

The solution is in `solution.md`. Try first.
