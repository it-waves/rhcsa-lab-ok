# Practice task: greet every argument

Work in your home directory.

1. Create the folder `lab17`.
2. In it, create a script `hello.sh` (use vim).
3. For every argument given to the script, it prints `Hello, ` followed by the argument. With no arguments it prints nothing.
4. Make the script executable.
5. Reboot, then run the checker (`bash check.sh`).

Example: `lab17/hello.sh Zed Mia` prints `Hello, Zed` and `Hello, Mia` on two lines.

The solution is in `solution.md`. Try first.
