# Practice task: files and directories

Work in your home directory.

1. Create the directories `lab8/a` and `lab8/b` (one command).
2. Put a file `lab8/a/one.txt` that contains the word `data`.
3. Copy it into `lab8/b`.
4. Rename `lab8/a/one.txt` to `lab8/a/two.txt`.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
