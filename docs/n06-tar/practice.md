# Practice task: tar and gzip

Work in your home directory. You need the `project` directory from the video (a directory that contains `readme.txt`).

1. Make a gzip-compressed archive called `backup.tar.gz` of the `project` directory.
2. Create a directory called `lab6`.
3. Extract the archive into `lab6` using `-C`.
4. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
