# Practice task: install a Flatpak app

1. Make sure Flatpak is installed and the Flathub remote is added system-wide under the name `flathub`. Address: https://dl.flathub.org/repo/flathub.flatpakrepo
2. Install the app `org.gnome.Calculator` system-wide.
3. Make sure it is the only copy (not also installed for your user).
4. Practise the removal too: remove the app, remove the unused runtimes, then install the app again.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
