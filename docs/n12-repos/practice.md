# Practice task: your own repository

Work in your home directory. Install `createrepo_c` like in the video if you have not already.

1. Create the folder `lab12repo`.
2. Download the package `zip` into it (do not install it).
3. Build a repository in that folder.
4. Add it as a repository with `dnf config-manager`, and keep it enabled.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
