# Practice task: permissions

Work in your home directory.

1. Create the folder `lab10`.
2. Inside it, create the file `notes.txt` with permissions `640`.
3. Inside it, create a directory `shared` with permissions `750`.
4. Look at the result with `ls -l lab10`.
5. Reboot, then run the checker (`bash check.sh`).

The solution is in `solution.md`. Try first.
